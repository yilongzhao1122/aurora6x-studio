本地数据、菜单与位图布局检查通过。v3.3.2 尚未完成 SDK 编译、官方模拟器运行或真机验证；预览为示例数据，实际内存峰值、功耗和数据一致性仍需验证。

## English

- Dedicated 16px UI font for A0, A2, B0, A4 and C6; 22px digit ink height for C1.
- C1 retains all six selectable data typefaces. Other positions retain their existing font assignments.
- Complete source ZIPs with Chinese and English starting-language presets. Both support on-watch language switching.
- Chinese and English project descriptions, installation/settings guides, data notes, development notes and validation statements.
- Includes 32 central backgrounds, native icons, per-field menus and directly read daily total calories.

Extract the entire ZIP and open START_HERE.html. Compile using the official SDK, official fenix6xpro device package and your own developer key. No precompiled PRG is included.

Local data, menu and bitmap-layout checks passed. SDK compilation, official simulator execution and physical watch testing have not been completed for v3.3.2. Previews use sample data; peak RAM, battery use and live-data agreement remain unverified.
