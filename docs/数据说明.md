# 数据来源与显示

热量显示 `ActivityMonitor.getInfo().calories` 提供的当天总消耗。当前一次运动热量不等于全天活动热量；本项目不推算静息或活动热量。

步数、目标、距离、总热量等来自 ActivityMonitor；电池与太阳能强度来自 System；心率、血氧、海拔等按可用当前数据与 SensorHistory 历史样本读取；天气来自 Garmin Weather。精确字段与有效期策略见 `source/Metrics.mc`。数据是否可读取决于目标设备支持、权限、传感器与手机同步状态。太阳能强度不能解读为实际充电功率。

真实零值保留，缺失或失效值显示 --。模拟器的默认心率、海拔、血氧和天气输入不是佩戴者的真实数据。农历、节气及月相使用打包的历法数据，覆盖 2020–2040 年。
