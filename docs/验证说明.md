# v3.3.2 验证说明

本版已重新生成字体与离线设置助手。A0、A2、B0、A4、C6 使用 SmallPlus（16 号）；C1 使用 Ring0–Ring5，数字可见高度为 22 像素，字符 advance 保持原值。B3、C0 和下方四格的字体引用保留。

本地检查使用源码绘制测试替身与实际 FNT/PNG 位图，包括 636 组字体、时制及指标场景，检查字形交叠、屏幕范围和中央时钟的浅色背景覆盖。设置导出、菜单保存、指标语义和位置指南另有检查脚本。

这些检查不运行 Garmin VM，不构成模拟器或真机测试。v3.3.2 在当前环境未进行 SDK 编译、官方设备包模拟器运行和真机验证；不沿用旧版本的编译结果作为本版通过证据。

本次提供源码与预生成资源，不包含预编译 PRG。请使用官方 fenix6xpro 设备包及自己的密钥编译，并检查真实峰值 RAM、功耗、中文长文本、最大数值和传感器数据一致性。所有展示图使用示例数据。
