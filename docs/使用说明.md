# 安装、预览与手表设置

## 电脑准备

安装 VS Code 的 Garmin Monkey C 扩展，用 SDK Manager 安装 Connect IQ SDK，并下载 fenix6xpro 设备。安装 Java，确保 `java -version` 可运行。在扩展命令面板运行 Monkey C 的开发密钥生成命令，将密钥文件保存在项目 `keys/developer_key`。已有密钥可以复制到此处；不要上传密钥。

也可在 PowerShell 当前窗口指定：

```powershell
$env:GARMIN_DEVELOPER_KEY = 'D:\GarminKeys\developer_key'
.\00_Check_Environment.cmd
.\01_Run_Simulator.cmd
```

SDK 自动从 Garmin 的当前配置发现，也可直接指定：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Build.ps1 -KeyPath 'D:\GarminKeys\developer_key' -SdkPath 'D:\GarminSDK' -Run
```

## 先预览

双击 `设置助手.html`。调整背景、颜色、栏目和两组数字字体；导出 `config.json` 后覆盖项目同名文件，重新编译。页面使用示例数据，不能验证传感器数据。手表保存的设置可能覆盖编译默认值，真机请通过自定义菜单调整。

## 在模拟器调整

运行 `01_Run_Simulator.cmd`。打开 Simulation → Trigger App Settings。UP/DOWN 选择，START 进入或保存，BACK 取消或返回。顶部与图标、下方数据、时间与外观三组菜单分别管理对应位置。

- A0 顶部；A1 左上图标；A2 上部中央；A3 右上图标；A4 日期右侧。
- B0 日期；B1 主时间；B2 秒钟；B3 星期。
- C0 斜条进度；C1 左下圆环；C2 第一行左、C4 第一行右；C3 第二行左、C5 第二行右；C6 底部。

“时间与外观 → 时间数字字体”控制时分及秒钟；“数据数字字体”控制进度百分比、圆环数值和下方四格。各有六种选择。日期、星期与菜单使用统一 UI 字体。

完整位置图和每栏选项请打开根目录 `手表端设置.html`。

## 安装到手表

1. 双击 `02_Build_For_Watch.cmd`，确认 BUILD SUCCESSFUL。
2. USB 连接手表，打开 Garmin 存储。
3. 将 `bin/Aurora6X.prg` 复制到 `GARMIN/APPS`。
4. 安全弹出，拔下数据线。
5. 手表长按 UP/MENU → 表盘 → Aurora 6X Studio → START → 应用。具体菜单文字随固件语言略有不同。
6. 在该表盘选择自定义，调整栏目与字体。每次按 START 保存。

更新使用同名 PRG；不要清空 GARMIN/APPS/SETTINGS 或 DATA。

## 排查

- 密钥不存在：检查它是文件；使用环境变量或 -KeyPath 指定。
- 缺少 fenix6xpro：在 SDK Manager 下载设备包。
- 数据显示 --：查看数据来源、同步与传感器状态；模拟器须配置相关模拟输入。
- 内存报错：保存完整错误栈、固件/API 版本、主题和字体选项，在 Issues 提交。不要以电脑可用内存判断手表内存。
- 配置未变化：确认运行当前目录的脚本；用手表菜单修改已保存设置。

## 中英文下载包与字号

CN 包默认中文，EN 包默认英文，两者功能相同，均支持“时间与外观 → 界面语言”切换。已有设置可能覆盖包的默认语言。A0、A2、B0、A4、C6 为独立 16 号字体；C1 数字可见高度为 22 像素。其他位置保留原有字体。
