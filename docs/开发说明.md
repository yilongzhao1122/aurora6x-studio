# 开发与资源维护

源码位于 source，资源位于 resources，原图及字体许可位于 artwork。Windows 构建入口调用 tools/Build.ps1。

安装 Python 依赖后，执行：

```sh
python -m pip install -r tools/requirements-artwork.txt
python tools/generate_onwatch.py
python tools/generate_icons.py
python tools/make_settings_page.py
```

字体尺寸和 advance 在 tools/typography.py 中维护；菜单与位图图集需要一起再生成。主时间、秒钟和普通数据分别对应 Time、Sec、Data 字体族；SmallPlus 用于指定五处文字，Ring 用于 C1。运行时只加载当前选择的字形图集，切换菜单时释放表盘资源。

本地逻辑检查：

```sh
node tools/check_metrics.cjs
node tools/check_onwatch.cjs
node tools/check_settings.cjs
node tools/check_onwatch_guide.cjs
node tools/check_typefaces.cjs
python tools/check_typeface_pixels.py
```

这些测试不替代官方模拟器。发布前必须检查缺失值、大数字、语言切换、睡眠唤醒、所有主题、字体切换和资源峰值。发布附件通过 release/Publish.ps1 创建并附 SHA-256；不提交开发密钥。

数字的可见字形高度由 typography.py 的 cap 控制。当前主时间 58px、秒钟 33px、数据 20px；固定 advance 决定水平宽度。改动后需要同时再生成 FNT/PNG 和设置助手，并检查 onUpdate 的位置坐标。不要只修改 FNT 的 info size。

本版 SmallPlus 字号为 16，C1 数字高度为 22px；普通数据数字为 20px。提交代码后运行 `python release/package_source.py`，生成默认中文和英文的 ZIP 与 SHA256SUMS。可使用已登录的 GitHub CLI 或网页发布，详见 [English development notes](Development.en.md)。
