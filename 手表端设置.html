    3. 在模拟器或手表中操作

    在电脑上预览

    1. 完整解压项目到文件夹，例如 D:/GarminProjects/Aurora6X。
    2. 在项目根目录，双击 01_Run_Simulator.cmd。命令窗口开头应显示 3.3.2 - typefaces + total calories。
    3. 模拟器点击 Simulation → Trigger App Settings。
    4. 进入“顶部与图标 → A3”，应只有 4 项；A0 应有 7 项，A4 应有 3 项。
    5. 再进入“下方数据 → C5”，这里应有 28 项。START 保存，BACK 返回，再打开确认选项保留。

    更新并操作手表

    1. 双击 02_Build_For_Watch.cmd，等待 BUILD SUCCESSFUL。
    2. USB 连接手表，把新生成的 bin\Aurora6X.prg 复制到手表的 GARMIN\APPS，若已有同名文件则替换。
    3. 安全断开后，在表盘界面长按左中 UP/MENU → 表盘 → Aurora 6X Studio → 右上 START → 自定义。
    4. 短按 UP / DOWN 移动，START 进入或保存，BACK 逐层返回。青色小圆点表示已保存选项。
    5. 例如“顶部与图标 → A3 → 月相 → START”；返回后右上方的小图标变为月相。

    设置保存在手表本地。修改后按 START 保存，BACK 返回。

    如所有栏位显示相同选项列表，请先核对运行窗口是否为 3.3.2、是否从新目录运行，以及复制到手表的是否为本次 02 生成的 PRG。仅更新 HTML 教程不会更新手表程序。
